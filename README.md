# TradeTrust

Инструменты для проверки торговых идей на истории и для ручной (сначала демо) торговли
по трендовой системе. Ордеров программа не ставит и ключи API бирж не нужны —
используются только публичные рыночные данные Binance (`data-api.binance.vision`).

## Система

Свечи 4 часа, только покупки на споте, без плеча.

| Правило | Значение |
|---|---|
| Вход | EMA 20 пересекла EMA 50 снизу вверх → покупка по открытию следующей свечи |
| Фильтр (по желанию) | BTC закрыл прошлый день выше 200-дневной средней |
| Стоп | вход − 2 × ATR(14) |
| Выход | EMA 20 ниже EMA 50 → продажа по открытию следующей свечи, либо стоп |
| Размер позиции | потеря до стопа = 1% депозита (но не больше всего депозита) |
| Комиссия в тестах | 0,1% с каждой стороны |

## Установка

```bash
pip install -r requirements.txt
```

## Команды

```bash
# Что система говорит сейчас (по последней закрытой 4ч свече), с размером позиции под депозит
python -m tradetrust signals --deposit 1000
python -m tradetrust signals --deposit 1000 --only-actions   # показать только ВХОД / ВЫХОД

# Сравнить варианты системы на 25 монетах с 2021 года
python -m tradetrust backtest
python -m tradetrust backtest --coins BTC,ETH,SOL --interval 1d --since 2022-01-01

# Честная проверка: подбор параметров на 12 мес., проверка на следующих 6 мес., и так по кругу
python -m tradetrust walkforward
python -m tradetrust walkforward --btc-filter

# Журнал сделок
python -m tradetrust journal add --opened 2026-10-20 --coin ARB --side long \
    --entry 0.192 --stop 0.179 --qty 774 --followed-rules yes --reason "EMA cross 4h"
python -m tradetrust journal add --closed 2026-10-25 --coin ARB --side long \
    --entry 0.192 --stop 0.179 --exit 0.21 --qty 774 --fees 0.3 --followed-rules yes
python -m tradetrust journal
```

Свечи кэшируются в `data/`, отчёты сохраняются в `reports/`. Флаг `--offline` берёт данные из кэша.

## Первые результаты (19.10.2026, 25 монет, 4ч)

С 2022 года (включая медвежий 2022-й), медиана по монетам:

| Вариант | Доход | Просадка | Монет в плюсе |
|---|---|---|---|
| Купить и держать | −54% | −88% | 5/25 |
| EMA, весь депозит в сделку | −2% | −74% | 12/25 |
| **EMA, риск 1% + стоп 2 ATR** | **+35%** | **−24%** | **21/25** |
| EMA, риск 1% + фильтр BTC | +23% | −21% | 17/25 |

Walk-forward (параметры подбирались на прошлом, проверялись только на «невиданных»
отрезках 2022–2026): медиана +25,5%, в плюсе 23 из 25 монет. Это хуже, чем просто
взять грубые 20/50/2 — подбор параметров преимуществ не даёт, поэтому остаёмся на
грубых настройках.

Ограничения тестов: нет проскальзывания; монеты считаются по отдельности, хотя
движутся вместе (общий риск портфеля надо ограничивать); прошлое не гарантирует будущего.
Сначала — 3–4 недели на демо с журналом.

## Android-приложение

Папка `android/`: приложение на Kotlin. Показывает сигналы по 25 монетам с размером позиции под ваш
депозит, присылает уведомления о входе и выходе (проверка раз в час в фоне), показывает график монеты и
ведёт журнал сделок со статистикой. Ордеров не ставит: торгуете вы сами на бирже.

**Как получить APK.** GitHub Actions собирает его при каждом пуше. Сборка из `main` публикуется в
разделе **Releases** репозитория: откройте его на телефоне, скачайте `TradeTrust-N.apk` и установите
(Android попросит разрешить установку из этого источника). Новая версия ставится поверх старой,
журнал сохраняется.

Расчёт сигналов в приложении повторяет `tradetrust/backtest.py`. Тест `StrategyParityTest` сверяет
сделки на реальных свечах; данные для него готовит `python -m scripts.make_parity_fixture`.

Локальная сборка: `cd android && ./gradlew assembleRelease` (нужны JDK 17+ и Android SDK).

## Бот на сервере (Bybit)

`tradetrust/bot/` — бот, который сам ведёт сделки на споте Bybit по той же системе:
сигнал на закрытии 4ч свечи → покупка → стоп-лосс на бирже → выход по сигналу или по стопу.
Только спот, без плеча. Бот трогает только купленные им монеты; остальное на счёте не касается.

**Управление — через Telegram:** уведомления о сделках с кнопками «Купить / Пропустить», команды и
**мини-приложение** (кнопка «Открыть» в чате с ботом). Оно работает на любом устройстве с Telegram:
- «Обзор» — счёт, режим, пауза, сделки на подтверждение, позиции. Цены, результат позиций и капитал
  обновляются в реальном времени — напрямую из открытого потока цен Bybit (WebSocket), без нагрузки на сервер;
- «Портфель» — весь счёт Bybit, а не только часть бота: сумма в долларах и изменение за 24 ч, распределение по
  монетам, сколько у бота и сколько ваших средств (их бот не трогает), список активов с живыми ценами;
- «Сигналы» — 25 монет, у каждой карточка со свечным графиком, EMA, стопом и планом сделки;
  Графики: таймфреймы 1с (живая цена по секундам), 1м, 5м, 15м, 1ч, 4ч, 1Д, 1Н и масштаб кнопками,
  двумя пальцами или колесом мыши; решения бот принимает по 4ч;
- «Журнал» — график капитала (точка после каждой 4ч свечи) с худшей просадкой, статистика (прибыльные, итог,
  средний R, profit factor), сделки и события.
- «Настройки» — тема (авто / светлая / тёмная), режим и пауза, риск и лимиты, капитал бота, фильтр BTC
  и список монет. Изменения проверяются по допустимым границам, применяются сразу, сохраняются в базе бота
  (переживают перезапуск) и приходят отчётом в Telegram; «Сбросить» возвращает значения из `.env`.
  Параметры системы (EMA, ATR) меняются только в `.env`.

Мини-приложение — `miniapp/`: TypeScript, React, свои компоненты и тёмная тема, графики TradingView Lightweight Charts.
На телефоне — нижнее меню, в широком окне (Telegram Desktop) — боковая панель с режимом и паузой, график и список сигналов рядом.
Docker собирает его при установке, а раздаёт сам бот. Локально: `cd miniapp && npm ci && npm test && npm run build`.
Вход — по подписи Telegram (`initData`), пускает только
владельца бота (`TELEGRAM_CHAT_ID`). Свой домен не нужен: HTTPS выдаётся на `<ip>.sslip.io`.

**Режимы** (`MODE`, меняются командой `/mode` или в мини-приложении):
- `signals` — только присылает сигналы;
- `confirm` — присылает сделку с кнопками «Купить / Пропустить», покупает после нажатия;
- `auto` — покупает сам.

Выходы (по сигналу и стопу) всегда выполняются автоматически — это защита капитала.

**Защита:**
- риск на сделку 1% (`RISK_PCT`);
- не больше 25% капитала в одной монете;
- суммарный риск открытых позиций не больше 5%;
- не больше 5 позиций одновременно;
- дневной лимит убытка 3%: после него бот ставит на паузу новые сделки;
- если стоп не поставился, позиция сразу продаётся;
- если стоп пропал, бот ставит его заново;
- предложение сделки истекает через 60 минут; если цена ушла от сигнала, бот её не догоняет;
- `BOT_CAPITAL_USDT` ограничивает часть счёта, которой распоряжается бот.

### Установка (Ubuntu/Debian, 1–2 ГБ ОЗУ достаточно)

1. **Ключ Bybit.** Bybit → Профиль → API → «Создать новый ключ» → «Системный». Права выдайте только на
   торговлю спотом (Unified Trading → Trade). **Вывод средств не включайте.** Привяжите ключ к IP сервера.
   Для пробы на ненастоящих деньгах сначала переключитесь в Bybit в режим Demo Trading и создайте ключ там.
2. **Telegram.** Напишите @BotFather → `/newbot` → сохраните токен.
3. **На сервере:**
   ```bash
   curl -fsSL https://raw.githubusercontent.com/B760m670/TradeTrust/main/deploy/install.sh | sudo bash
   ```
   Установщик ставит Docker, спрашивает режим, ключи и Telegram и запускает бота. HTTPS-сертификат
   выпускается автоматически на адрес вида `<ip>.sslip.io`; у хостера должны быть открыты порты 80 и 443.
4. **В Telegram** откройте своего бота: кнопка «Открыть» запускает мини-приложение.

**Если на сервере уже есть сайт или VPN.** Установщик не занимает порты 80/443: бот слушает только
`127.0.0.1:8090` (или следующий свободный порт). Если там работает Caddy, установщик добавляет в
`/etc/caddy/Caddyfile` один блок для адреса бота — с резервной копией и проверкой `caddy validate`; при ошибке
возвращает файл как был. Образ скачивается готовым из GitHub (ghcr.io), а память бота ограничена 400 МБ.

Рекомендуемый порядок: `paper` (бумажный счёт) → `demo` (демо Bybit) → `mainnet` с небольшой суммой.
Переключение: `BYBIT_ENV` в `/opt/tradetrust/.env`, затем `cd /opt/tradetrust && docker compose up -d`.

**Telegram-команды:** `/app`, `/status`, `/signals`, `/trades`, `/report`, `/mode signals|confirm|auto`, `/pause`, `/resume`,
`/close BTC`, `/closeall`.

**Обслуживание:**
- логи: `cd /opt/tradetrust && docker compose logs -f bot`;
- обновление: автоматически раз в час (systemd-таймер `tradetrust-update.timer`, ставит установщик); бот
  перезапускается, только если вышла новая версия. Журнал: `journalctl -u tradetrust-update`, отключить:
  `systemctl disable --now tradetrust-update.timer`;
- ежедневная сводка в Telegram (капитал, итог за сутки, позиции) — время и вкл/выкл в «Настройках», по запросу — `/report`;
- данные бота (позиции, журнал): `/opt/tradetrust/botdata/bot.db`.
